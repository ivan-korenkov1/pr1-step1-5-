# Эмулятор командной оболочки UNIX

Практическая работа № 1 по дисциплине «Конфигурационное управление»,
вариант № 12. Язык реализации - Python 3.

## Общее описание

Консольное приложение, которое имитирует командную строку
UNIX-подобной ОС. Приглашение к вводу строится по реальным данным
ОС: `имя_пользователя@имя_компьютера:~$`.

Весь код находится в одном файле `src/emulator.py`:

- `get_prompt()` - формирует приглашение;
- `act(line)` - разбирает строку на команду и аргументы по пробелам
  и выполняет команду;
- `repl()` - цикл «прочитать команду - выполнить - напечатать».

## Команды

| Команда | Описание |
|---|---|
| `ls [аргументы]` | заглушка: выводит имя команды и аргументы |
| `cd [путь]` | заглушка: выводит имя команды и аргументы |
| `exit` | выход из эмулятора |

Ошибки: неизвестная команда (`foo: команда не найдена`), неверные
аргументы (`cd: слишком много аргументов`).

## Запуск и тесты

```bash
./run.sh                    # или python3 src/emulator.py
bash tests/test_repl.sh     # демонстрация REPL (этап 1)
```

## Пример

```
ivan@macbook:~$ ls -l
ls ['-l']
ivan@macbook:~$ cd a b
cd: слишком много аргументов
ivan@macbook:~$ foo
foo: команда не найдена
ivan@macbook:~$ exit
```
