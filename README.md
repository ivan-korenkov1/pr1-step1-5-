# Эмулятор командной оболочки UNIX

Практическая работа № 1 по дисциплине «Конфигурационное управление»,
вариант № 12. Язык реализации - Python 3.

## Общее описание

Консольное приложение, которое имитирует командную строку
UNIX-подобной ОС. Приглашение к вводу строится по реальным данным
ОС: `имя_пользователя@имя_компьютера:~$`.

Весь код находится в одном файле `src/emulator.py`:

- `get_prompt()` - формирует приглашение;
- `act(line)` - разбирает строку на команду и аргументы по пробелам
  и выполняет команду;
- `run_script(path)` - выполняет стартовый скрипт;
- `repl()` - цикл «прочитать команду - выполнить - напечатать»;
- `main()` - читает параметры запуска.

## Параметры запуска

```bash
python3 src/emulator.py [путь_к_VFS] [путь_к_стартовому_скрипту]
```

При запуске печатаются все заданные параметры (строки `[debug]`).

## Стартовый скрипт

Текстовый файл, в каждой строке одна команда. Пустые строки и
строки, начинающиеся с `#`, пропускаются. На экран выводятся
приглашение, команда и результат, как в диалоге с пользователем.
На первой ошибке скрипт останавливается, эмулятор завершается
с кодом 1. Если скрипт закончился без `exit`, дальше работает REPL.

## Команды

| Команда | Описание |
|---|---|
| `ls [аргументы]` | заглушка: выводит имя команды и аргументы |
| `cd [путь]` | заглушка: выводит имя команды и аргументы |
| `conf-dump` | параметры эмулятора в формате `ключ=значение` |
| `exit` | выход из эмулятора |

Ошибки: неизвестная команда (`foo: команда не найдена`), неверные
аргументы (`cd: слишком много аргументов`).

## Запуск и тесты

```bash
./run.sh                    # или python3 src/emulator.py
bash tests/test_repl.sh             # REPL (этап 1)
bash tests/test_params.sh           # параметры запуска (этап 2)
bash tests/test_params_errors.sh    # ошибки запуска и скрипта (этап 2)
```

## Пример

```
$ python3 src/emulator.py vfs.zip
[debug] Параметры запуска:
[debug]   vfs = vfs.zip
[debug]   script = None
ivan@macbook:~$ conf-dump
vfs=vfs.zip
script=None
ivan@macbook:~$ ls -l
ls ['-l']
ivan@macbook:~$ cd a b
cd: слишком много аргументов
ivan@macbook:~$ foo
foo: команда не найдена
ivan@macbook:~$ exit
```
